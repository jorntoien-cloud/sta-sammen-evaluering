# Stå sammen – Evalueringsanalyse

Webapp for å hente og analysere evalueringer fra Miro-boards i Consto sitt "Stå sammen"-program.

## Kom i gang

1. Gå til appens URL (GitHub Pages)
2. Logg inn med Miro Access Token og Anthropic API-nøkkel
3. Hent boards og kjør analyse

## Kjøre lokalt (for automatisk innlogging)

```bash
npx serve -p 3456 .
```

Legg til en `config.json` med dine nøkler (se `config.json`-eksempel – denne filen skal IKKE committes).
